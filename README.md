# Hiking Weather

Minimales Grundgerüst mit Vite, React und TypeScript im Strict-Modus.
Komponenten nutzen CSS Modules (`*.module.css`); globale Basisregeln stehen in `src/index.css`.

## Entwicklung

Voraussetzung: Node.js 22.12+.

```sh
npm install
npm run dev
```

## Build und Prüfung

```sh
npm run build   # TypeScript prüfen und Produktionsbuild erstellen
npm run lint    # Code mit Oxlint prüfen
npm run preview # Produktionsbuild lokal ansehen
```
